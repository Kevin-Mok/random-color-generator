# Random Color Generator

An interactive web application that generates and displays random colors with name approximation.

![HTML5](https://img.shields.io/badge/HTML5-Web-orange)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![Bootstrap](https://img.shields.io/badge/Bootstrap-4-purple)

## Overview

A simple, elegant web tool for generating random colors on click. Features color name approximation using ntc.js, history navigation, and a clean responsive interface. Great for designers seeking color inspiration.

## Features

- **Random Colors** - Generate attractive colors on click
- **Color Naming** - Approximate color names with ntc.js
- **History Navigation** - Browse previous colors
- **Hex/Name Toggle** - Switch between hex codes and names
- **Responsive Design** - Works on all screen sizes

```bash
# Clone repository
git clone git@github.com:Kevin-Mok/random-color-generator.git
cd random-color-generator

# Open in browser
open index.html
```

Or visit the live demo directly.

## Usage

1. **Click anywhere** to generate a new random color
2. **Use arrows** to navigate color history
3. **Hover** to reveal navigation buttons
4. **Click color text** to toggle between hex and name
